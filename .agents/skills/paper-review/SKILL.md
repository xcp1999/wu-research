# 机器人论文速读

调用本技能时，直接更新用户指定的文档，默认写入项目的 `papers.md`。写前重读目标文件并核对版本，按项目 `AGENTS.md` 更新已有条目或新增条目。写入并确认后只回复「已更新xxx论文」。

先读论文与官方仓库，按以下顺序写摘要。推理和训练数据流可用 `text` 代码块或 Markdown 表格。流程图用 `text` 代码块保留换行和缩进，多阶段流程可用表格。推理说明观测、关键模块、输出及执行接口。训练说明数据来源、训练信号和更新对象。

````markdown
## 简称 — 完整标题

[论文](URL) · [项目主页](URL) · [代码](URL)

**作者** 按署名顺序列前两位，另列通讯作者及论文署名单位。**录用** 会议或期刊、年份及明确的录用状态。

**论文公开日期** YYYY-MM-DD · **代码与录用核查日期** YYYY-MM-DD

**开源情况** 可推理（范围）；可复现训练（范围）；可复现真机（平台）。简记缺项。

**核心问题** 用一句话概括论文试图解决的问题。

**推理数据流**

```text
观测 → 模块 → 动作或输出 → 执行
```

**训练数据流**

```text
数据来源 → 训练信号或目标 → 更新的模块
```
````

## 数据流示例

**推理数据流**

```text
头部相机图像 + 语言指令 → Qwen3-VL → 视觉语言特征
视觉语言特征 + 当前本体观测 → 动作专家 MM-DiT
  ↓
未来 H 步动作（每步 36 维）
  ├─ 28 维 → 双臂、双手关节目标
  └─  8 维 → AMO → 15 个腰腿关节目标
  ↓
G1 执行 → 采集新观测
```

**训练数据流**

| 阶段 | 数据怎么流 | 更新谁 |
|---|---|---|
| 预训练 | EgoDex 人体视频、Humanoid Everyday 机器人数据 → 双腕位姿和指尖位置 → FAST 动作 token → 预测下一步动作 token | Qwen3-VL |
| 后训练 | Humanoid Everyday 的关节动作 → 给动作加噪 → 用视觉语言特征和本体状态做条件，以 flow matching 学习生成动作块 | 动作专家从头训练，VLM 冻结 |
| 任务微调 | 每项任务 80 条 G1 遥操作轨迹 → 用示范中的全身动作块继续训练 | 主实验只微调动作专家，AMO 直接复用 |
## 核查与写入

- **开源** 分别判断推理、训练、真机。检查实际公开的入口、配置、权重、必要资产及数据或数据生成流程。只覆盖部分任务或只支持微调时，写清范围；缺训练代码、数据或真机集成时简写所缺材料。信息不足写「未核实」，材料核验与实际运行按各自证据表述。
- **作者与录用** 中国作者用能核实的汉字姓名，其他姓名沿用论文原文。单位按论文署名，通讯作者与前两位重合时合并标注。录用优先查会议／期刊官网、论文集或公开评审决定；作者明确标为在审时可注明，未找到公开录用信息时写「未查到公开录用记录」。
- **日期** 论文公开日期取首次公开版本的日期。代码与录用核查日期取本次检查两项信息的日期。两个日期各写一次。
- **链接** 只列论文、项目主页、代码三个官方入口。未公开的入口省略。省略重复的系统表、背景、实验细节和延伸问答。
